ILSA

Extension + local engine

The extension captures signs in Meet. Recognition runs in a program on your PC: the ILSA window. Download it, open it, and leave that window open while you are in the call.

1. Download and start ILSA

It is a single program. If it comes in a zip, unzip it and open ILSA.exe. You do not need to install Python.

Windows may ask for “more info → run anyway” (the exe is unsigned). Leave the ILSA window open.

2. Engine status

ILSA is not visible on this machine yet…

3. Open Google Meet

With ILSA on (green), open Google Meet: translation starts on its own. If you do not want it, Stop ILSA in the exe.
